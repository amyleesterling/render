Render examples

Neuron renders made with the pipeline in this repository. Each one lists the scripts that produced it, so you can go from a picture you like to the code behind it.

The stages are in RENDERING.md. Every script is in INVENTORY.md.

CA3, mouse hippocampus MICrONS, mouse cortex Eyewire II, mouse retina BANC, fly brain and nerve cord No GPU

CA3, mouse hippocampus

Blender 4.4, EEVEE, 64 samples. The population is imported once into a scene cache, and every shot opens the cache and rebuilds only materials, lights, camera and keyframes. More on the CA3 site.

MICrONS, mouse visual cortex

One Blender unit per micrometre. Squeezing this volume into ten units made half micrometre dendrites too thin for the renderer to draw. More on the MICrONS site.

Eyewire II, mouse retina

Here brightness is a measurement, so emission carries it. The scene is still lit. More on the retina site.

BANC, fly brain and nerve cord

A still. The animation of this scene is on the review shelf and has not been published. More on the BANC site.

No Blender, no GPU

Meshes through CAVE, drawn in three.js, captured frame by frame from headless Chromium into ffmpeg. This runs in a cloud session with no graphics card.
